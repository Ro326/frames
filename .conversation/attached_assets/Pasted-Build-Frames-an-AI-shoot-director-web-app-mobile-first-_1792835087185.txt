Build "Frames" — an AI shoot director web app, mobile-first (creators use it on their phone while shooting).

STACK: React + Vite frontend, Node/Express backend, Replit Postgres (or Replit DB). Use Replit's AI integration (Anthropic Claude with vision) for all AI calls. Deploy publicly.

USER FLOW (4 screens):
1. SIGN UP: name, email, phone. Store with timestamp in `users` table (this is our proof of real users).
2. BRIEF: user types what they're shooting (e.g. "60-sec reel vlog of AI Builders Day"), picks niche (vlog/travel, food, fitness, product, event, other), target length, vibe. Option A: "Generate plan" (AI). Option B: "I'll write my own" (user adds shots manually).
3. PLAN: call DIRECTOR prompt → returns JSON shot list. Show as cards in order: slot number, section (Intro/Body/Outro), shot description, angle, movement, type (A-roll/B-roll), objects/props to capture, duration, niche tip. Also show: voiceover script, packing/prep checklist. User can edit, reorder, delete, add cards. Button "Approve plan" (log approval with timestamp).
4. SHOOT & CHECK: each slot card has "Upload clip". On upload, extract 3 frames IN THE BROWSER (video element + canvas at 20%, 50%, 80% of duration, JPEG ~512px). Send frames + slot description to backend → FRAME CHECKER prompt → returns JSON {match, confidence, verdict, fix}. Show: green ✅ "Go ahead" or amber ⚠️ with the fix text. Buttons: "Retake" or "Approve anyway" (human override — log it). Top bar shows coverage: X/Y slots done, missing slots in red with "Shoot this next: ...".
5. EDIT TABLE (unlocks when all slots approved): "Download pack" → client-side JSZip of all clips renamed `01_Intro_building-wide.mp4` etc., plus `shot_sheet.md` (order, descriptions, verdicts) and `voiceover.txt`. Button "Generate voiceover audio" → ElevenLabs TTS API on the VO script, play + download mp3.

AGENT LOG: table `agent_events` (user_id, agent_name, input_summary, output_json, human_decision, timestamp). Log every Director, Frame Checker and approval event. Add an /admin page (password-protected) showing users count, events, and timestamps — we screenshot this for judges.
